# Contributing

## Ветки

Работа ведётся только через Pull Request в `main` — прямой push запрещён настройками репозитория.

| Префикс | Когда используется |
|---|---|
| `feature/<кратко>` | новая функциональность |
| `fix/<кратко>` | исправление бага |
| `chore/<кратко>` | рутина: конфиги, зависимости, инфраструктура |
| `docs/<кратко>` | только документация |
| `refactor/<кратко>` | изменение кода без изменения поведения |

## Коммиты

Формат: `<тип>: <краткое описание>`

- `feat:` — новая функциональность
- `fix:` — исправление бага
- `chore:` — рутина (конфиги, зависимости, инфраструктура)
- `docs:` — только документация
- `refactor:` — изменение кода без изменения поведения
